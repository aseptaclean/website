# Historical archive

Everything below this directory is non-authoritative historical evidence. It is retained for
traceability, not as a source for implementation, public copy, route status, claims, visual
tokens, or release decisions.

Do not restore content from this archive because a filename says `FINAL`, `APPROVED`, `UPDATED`,
`MASTER`, or `CANONICAL`. A current owner decision, `AGENTS.md`, active claims law, current source,
and a fresh production build all outrank these files.
