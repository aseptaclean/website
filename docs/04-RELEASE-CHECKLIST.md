# Release Checklist

## Business and offer
- [ ] Handoff Reset is unmistakably the single flagship offer.
- [ ] The first meaningful screen explains who it is for, what outcome it creates, and the next action.
- [ ] Primary CTA is consistently `Get My 24-Hour Handoff Plan`.
- [ ] $1,500 starting context is clear and accurately framed.
- [ ] $195 assessment terms are accurate and centralized.
- [ ] One-business-day response commitment is stated consistently.
- [ ] Poor-fit routine housekeeping and small pickup work are not encouraged.

## Claims and trust
- [ ] No invented reviews, projects, results, clients, team, fleet, certifications, or regulatory status.
- [ ] Founder background is accurate and does not imply regulated authority.
- [ ] Scope, exclusions, stop-work conditions, and change authorization are clear.
- [ ] Sample documents are visibly labeled as samples.
- [ ] Insurance and license claims match current proof or are suppressed.
- [ ] Required disclaimers are present.

## Visual authorship
- [ ] Hero could not belong to a generic SaaS company, agency, cleaner, or junk hauler after a logo swap.
- [ ] Custom Handoff Record/scope artifact is central and credible.
- [ ] No generic AI visual blacklist patterns accumulate.
- [ ] Section density and spacing follow content importance rather than a repeated template.
- [ ] Founder presentation feels real and accountable.
- [ ] Footer provides deliberate closure.

## Responsive and interaction
- [ ] Mobile section order was designed intentionally.
- [ ] No horizontal overflow at 320px.
- [ ] H1/H2 wraps reviewed at all required widths.
- [ ] Sticky actions do not cover fields, buttons, cookie controls, or footer actions.
- [ ] All interactive elements have required states.
- [ ] Form preserves input after errors.
- [ ] Uploads communicate type, size, progress, failure, and removal.
- [ ] Reduced motion is respected.

## Accessibility
- [ ] One H1 and logical heading order.
- [ ] Landmarks and labels are semantic.
- [ ] Keyboard navigation works.
- [ ] Focus is visible.
- [ ] Body text meets contrast requirements.
- [ ] Primary controls meet target-size requirements.
- [ ] Errors are associated with fields and announced appropriately.
- [ ] Page reflows without loss at zoom.

## Performance and SEO
- [ ] LCP, INP, CLS, JS, and page-weight budgets pass.
- [ ] Images have dimensions, responsive sources, and correct loading priority.
- [ ] Fonts are optimized without layout shift.
- [ ] Unique title, description, canonical, OG metadata, and one H1 exist.
- [ ] Structured data is accurate and validates.
- [ ] Sitemap and robots behavior are correct.
- [ ] Staging is noindex.

## Operations
- [ ] Required environment validation passes.
- [ ] Public phone and form endpoint are real.
- [ ] Real submissions reach the correct destination.
- [ ] Notification path works.
- [ ] Thank-you route is noindex and conversion tracking is verified.
- [ ] No visible placeholder remains.

## Release gate
- [ ] Quality score is at least 90/100.
- [ ] No noncompensable failure remains.
- [ ] Final decision and evidence are recorded.
